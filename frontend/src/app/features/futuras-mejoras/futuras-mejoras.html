Futuras mejoras

GoGaming está en constante evolución. Estas son las funcionalidades que tenemos planificadas para próximas versiones.

Gestión de direcciones en el perfil de usuario

Mejora prioritaria

Se implementará un apartado de direcciones dentro del perfil que permita guardar varias direcciones y seleccionar una como predeterminada para agilizar el proceso de checkout.

Validación de tarjeta y métodos de pago reales

GoGaming actualmente simula el proceso de compra sin cobro real. La solución planteada es integrar Stripe como pasarela de pago principal, soportando tarjeta de crédito, débito, Apple Pay y Google Pay.

Sistema de rastreo de paquetes

El seguimiento de pedidos actualmente es manual. Se plantea integrar APIs de transportista para que el cliente pueda consultar el estado de su envío en tiempo real directamente desde su perfil, sin necesidad de acceder a la web del transportista.

Sistema de reportes

La plataforma carece de un sistema que permita denunciar reseñas fraudulentas o comentarios inapropiados. Se implementará un botón de reporte en cada reseña junto con un panel de gestión en el dashboard para que el administrador pueda revisar y actuar sobre el contenido denunciado.

Corrección del inicio de sesión con Google

El login con Google está parcialmente implementado pero presenta fallos en producción. La mejora consiste en revisar la configuración OAuth2 en Google Cloud Console, corregir los redirect URIs para el dominio gogaming.es y garantizar que el flujo de creación de usuario mediante Google sea consistente con el sistema JWT existente.

Buscador de productos

La barra de búsqueda en el header es actualmente visual y no funcional. La mejora consiste en implementar un buscador global que permita buscar por nombre o marca entre todos los tipos de producto (ratones, teclados, skates, alfombrillas, auriculares y mangas), mostrando los resultados en una página dedicada con filtros y paginación.

Pop-ups y alertas modernas

Actualmente la aplicación usa alert() nativo del navegador para comunicar acciones al usuario, lo que rompe la experiencia visual. Se plantea sustituirlos por notificaciones toast o modales integrados en la interfaz, coherentes con el diseño de GoGaming, para confirmar acciones como añadir al carrito, guardar cambios o mostrar errores de validación.
